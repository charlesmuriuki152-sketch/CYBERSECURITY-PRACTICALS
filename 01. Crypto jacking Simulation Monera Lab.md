## 6. P2Pool build
Commands:
```bash
git clone https://github.com/SChernykh/p2pool.git ~/p2pool
cd ~/p2pool
git -c http.version=HTTP/1.1 submodule update --init --recursive --depth 1
```

After installing the dependency libcurl4-openssl-dev:
```bash
cd ~/p2pool
rm -rf build
cmake -S . -B build -DWITH_RANDOMX=OFF
cmake --build build -j2
```

Build completed successfully. Executable: ~/p2pool/build/p2pool.

## 7. Android ADB and scrcpy preparation

Commands:

Use the current IP and ports shown in Android Wireless Debugging. Pairing and connection ports are different.

## 8. Cryptojacking awareness
Cryptojacking means using another person's computing resources to mine cryptocurrency without informed permission.

Possible warning signs:
- Unexplained high CPU usage or overheating
- Unknown mining processes
- Suspicious startup tasks or repeated process restarts
- Unexpected network activity

Basic Linux process checks:
```bash
ps aux --sort=-%cpu | head
top
```

Prevention: obtain explicit consent, use trusted software, monitor CPU and network activity, keep systems updated, and never expose Monero daemon RPC publicly.
